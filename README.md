# Pindi Boys Car Rental Website

Premium marketing website for **Pindi Boys Car Rental LLC**, designed to rival leading global rental brands.

## Getting started

1. Open `index.html` in your preferred browser.
2. Adjust content, imagery, or pricing by editing the HTML in the respective sections.
3. Customize colours, typography, and spacing inside `assets/css/style.css`.
4. Enhance interactions or integrations through `assets/js/main.js`.

## Structure

```
index.html                # Landing page markup
assets/
  css/style.css           # Global styling
  js/main.js              # Navigation & form behaviour
  images/                 # Drop-in folder for brand imagery
```

## Features

- Modern hero with rapid reservation form and trust metrics
- Curated fleet showcase with quick-reserve shortcuts
- Story-driven sections for experience, offers, testimonials, and insights
- High-converting contact and newsletter capture forms
- Responsive design with smooth scroll, reveal animations, and mobile navigation drawer

## Customisation ideas

- Replace placeholder text, offers, and partner logos with live data
- Embed third-party booking engines or CRM integrations inside `main.js`
- Populate `assets/images` with branded photography or car visuals
- Add analytics, live chat widgets, or multilingual support as needed
